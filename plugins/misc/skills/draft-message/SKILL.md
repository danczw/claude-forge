# Draft message

- Write in the language of the request or the thread being answered.
- Shortest version that carries the point; plain prose, no bullets unless asked.
- Fit the audience: outsiders get no internal ticket numbers, code or project detail.
- No emojis, filler openers or sign-off fluff.
- Asked for options: give N numbered, clearly different variants.

Return only the message text, ready to paste.
